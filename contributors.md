## Special Thanks

VeTube builds on the shoulders of giants. Special thanks to:

### Open Source Projects

- **[Piper TTS](https://github.com/rhasspy/piper)** — High-quality neural text-to-speech
- **[BASS Audio Library](https://www.un4seen.com/)** — Professional audio playback
- **[wxPython](https://www.wxpython.org/)** — Cross-platform GUI toolkit
- **[yt-dlp](https://github.com/yt-dlp/yt-dlp)** — YouTube and video platform support
- **[chat-downloader](https://github.com/xenova/chat-downloader)** — Multi-platform chat extraction
- **[TikTokLive](https://github.com/isaackogan/TikTokLive)** — TikTok live chat integration
- **[kick.py](https://github.com/iamoverit/kick.py)** — Kick platform integration
- **[discord.py](https://github.com/Rapptz/discord.py)** — Discord bot framework
- **[cx_Freeze](https://github.com/marcelotduarte/cx_Freeze)** — Python application packaging

### Tools and Services

- **[GitHub](https://github.com/)** — Code hosting and collaboration
- **[Scoop](https://scoop.sh/)** — Windows package manager
- **[uv](https://github.com/astral-sh/uv)** — Fast Python package manager
- **[Python](https://www.python.org/)** — Programming language

### Community

- All users who have reported bugs and suggested features
- Everyone who has shared VeTube with their audience
- Streamers who use VeTube and provide feedback

## How to Contribute

Want to see your name on this list? There are many ways to contribute:

- **Code**: Fix bugs, add features, improve performance
- **Documentation**: Write guides, improve this documentation, translate
- **Testing**: Report bugs, test new features, provide feedback
- **Translations**: Add or improve translations
- **Support**: Help other users in discussions

Check the [Contributing Guide](contributing.md) to get started!
