# VeTube

VeTube позволяет доступно читать сообщения и управлять чатами YouTube, Twitch, Kick, TikTok, QuentinC Playroom и Discord — как на своих трансляциях, так и на трансляциях любимых авторов.

В Discord программа может читать текстовые каналы сервера. Подробности приведены в [пошаговом руководстве по настройке](discord.md).

## Возможности

- Автоматический режим: чтение входящих сообщений чата в реальном времени с помощью выбранного синтезатора речи или программы экранного доступа.
- Невидимый интерфейс: управление чатами из любого окна с помощью простых сочетаний клавиш. Для этого должна быть запущена программа экранного доступа.
- Поддерживаемые программы экранного доступа:
  - NVDA;
  - JAWS;
  - Window-Eyes;
  - SuperNova;
  - System Access;
  - PC Talker;
  - ZDSR.
- Гибкая настройка программы:
  - включение и выключение звуков;
  - включение и выключение автоматического чтения;
  - настройка списка сообщений в невидимом интерфейсе;
  - настройка голоса.
- Быстрое переключение режима чтения чата: можно читать все сообщения либо только сообщения участников или пожертвования.
- Добавление прямых эфиров в избранное: к сохранённому чату можно вернуться, не разыскивая ссылку повторно.
- Перевод сообщений чата на другой язык.

## Участие в переводе

Чтобы помочь с переводом VeTube на другой язык, установите средства интернационализации.

1. Установите Babel:

   ```bash
   pip install Babel
   ```

2. Извлеките строки и обновите шаблон `.pot`. Если в код были добавлены новые строки, выполните:

   ```bash
   pybabel extract -F babel.cfg -o VeTube.pot .
   ```

3. Создайте новый перевод. Например, для итальянского языка с кодом `it`:

   ```bash
   pybabel init -i VeTube.pot -d locales -l it -D VeTube
   ```

4. Обновите существующие переводы после изменения шаблона `.pot`:

   ```bash
   pybabel update -i VeTube.pot -d locales -D VeTube
   ```

5. Скомпилируйте файлы `.po` в `.mo`, чтобы программа распознала изменения:

   ```bash
   pybabel compile -d locales -D VeTube
   ```
